Project 02

Grocery Market Prices

A comparative retail application created to make grocery and market pricing easier to understand by presenting useful information in a clear, accessible format.

GitHub Repository Project Overview

Overview

This project explored how pricing information can be organized to help users compare products more easily. The emphasis was on building a straightforward interface where data feels understandable and visually readable.

Tech Stack

HTML5 React Next.js Tailwind CSS API Integration

Key Highlights

  • • Data-driven design approach for a practical comparison experience.
  • • Improved my understanding of using frontend logic with structured datasets.
  • • Focused on clarity, readability, and user-friendly presentation.
  • • Strengthened problem-solving in real-world data presentation scenarios.
