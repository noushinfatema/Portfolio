About me!

I am a passionate frontend web developer with a strong interest in creating clean, modern, responsive, and user-friendly websites. My core skillset includes HTML for building structured web pages, Tailwind CSS for designing fast and responsive layouts, and JavaScript for adding interactivity and dynamic functionality. I am comfortable working with sections, navigation bars, buttons, cards, forms, image layouts, hover effects, and responsive designs for different screen sizes.
I also enjoy building project-based interfaces such as portfolio websites, e-commerce pages, movie app layouts, learning management system designs, and creative web applications. I focus on writing organized code, maintaining clean layout structure, improving user experience, and designing websites that look professional on both desktop and mobile devices. I am continuously learning new frontend techniques and improving my ability to turn ideas into real digital products.
