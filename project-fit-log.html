Project 01

Fit Log

A fitness-focused platform designed to help users monitor workout habits, track progress, and keep personal wellness goals organized in a clean, experience-driven interface.

GitHub Repository Project Overview

Overview

Fit Log was built to explore the idea of a personal fitness dashboard that is both practical and motivating. The project focuses on helping users stay on track with their health goals and improving how workout data is presented.

Tech Stack

React Next.js Tailwind CSS MongoDB REST API

Key Highlights

  • • Clean, modern dashboard layout for fitness tracking.
  • • Focus on responsive design and smooth user experience.
  • • Built to understand how health-related data can be shown clearly and effectively.
  • • Strengthened my understanding of frontend structure, styling, and project planning.
